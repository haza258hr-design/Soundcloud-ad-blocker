# Soundcloud ad blocker
Soundcloud Ad blocker - Stops ads 100% completely. Those ads are so stupid and annoying so i made this as a broswer extension to block those ads so you can listen for free for ever no subscriptions like it should be.

You need to first download the .zip or the folder.

I personally use brave to stop ads, but you can use whatever browser you like.

Go in Browser extensions, active developer mode then add this extension, its really that simple.

You need to select the entire folder as the plugin not 1 single file.
